How the real tool would make this

From a code file to a two-minute lesson

  1. Read the code. Parse the function, find the loop, the branches and every variable that changes.
  2. Plan seven beats. Hook, idea, code, trace, payoff, trap, recap, fitted to 120 seconds.
  3. Run it for real. Execute on a small input and record each line and variable change. The trace drives the animation.
  4. Write one sentence per visual change. Keywords are tagged with the ink of the thing they name on screen.
  5. Compose from scene templates. Array stage, number line, race chart, bug card, recap cards.
  6. Render deterministically. Every frame is a function of time, so the same page exports to MP4 at 60 fps with a TTS voice track.
